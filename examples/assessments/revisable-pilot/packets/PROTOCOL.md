# Prospective continuation pilot, edition 1

Freeze before the first recipient. Six fresh recipient contexts, three per condition,
three sequential stages each. Order: structured-1, prose-1, structured-2, prose-2,
structured-3, prose-3. Up to three runs may overlap; stages within a run may not.
All use the root's inherited model, reasoning setting and available tools, with no
model override. The orchestration API does not expose a model version, sampling seed,
temperature or actual token allocation; do not invent them. Identical instructions
limit each stage to one file-read call and an 800-word response. Tool visibility is
shared; behavioral file restrictions are not an OS sandbox. Fresh contexts receive
no parent turns (`fork_turns: none`), scoring keys, future packets or other responses.
They receive TASK.txt verbatim in their initial message and one isolated packet path.
Later messages supply only the next isolated packet path and the same stage task.
No correction or score is fed back. Preserve every attempted response and protocol
violation. Do not rerun a weak response. If an infrastructure failure requires a
retry, retain it and report the retry as an additional attempt.

Both conditions contain exactly the same substantive records, identifiers, dependency
links, quotations, source metadata and boundaries. JSON groups them as fields;
competent prose uses labelled paragraphs and explicit dependencies. No diagrams,
extra explanations, access to source pages, or reference answers distinguish them.
The deterministic parity receiver must recover identical record values from both
formats before freezing. Packets are incremental at updates, with equal access to
one's previous context. Recipients do not receive a corrected canonical assessment.

Primary descriptive score: eight binary dimensions at each stage, 24 per run.
Score semantic content, not wording, JSON polish or condition. Report each run and
condition totals; no significance test, population effect, superiority or human
benefit claim is justified by three runs. Root reviews every score against evidence;
an isolated scorer receives condition-blinded responses and the same rubric after
all recipient stages finish. Disagreements are retained and adjudicated explicitly.
No post-hoc primary metric or exclusion. Tool counts, protocol violations and byte
sizes are diagnostics; do not fabricate latency/token measures unavailable from tools.

This familiar historical case may be known to every model. Instructions cannot erase
pretraining. Same-model recipients and scorer are not independent human replication.
A ceiling or no observed difference is a valid result. A structured representation's
exact reference checking is distinct from an empirical benefit in continuation.

## Frozen rubric

Each dimension is 0 or 1; partial/absent/contradictory earns 0. Cite response evidence.
1. Source binding: uses only available S0 / S0,S1 / S0,S1,S2 respectively; distinguishes
   publisher reports from analyst conclusions. No unsupplied historical facts.
2. H1: stage 0 provisional/unestablished; stage 1 still unestablished (not settled by
   possible faults); stage 2 no longer supported by this anomaly, without universal
   impossibility claims.
3. H2/H3: stage 0 retains H2 under dispute and H3 as possible; stage 1 reopens H2 and
   does not declare a measured net fault effect or eliminate H3 without warrant;
   stage 2 favours the source-attributed H2 while distinguishing H3's lack of support
   from proof that every possible analysis artefact is absent.
4. Assumption/disagreement: stage 0 identifies A1 as disputed, not source-established;
   stages 1/2 withdraw A1 for current use and preserve D1 as the historical objection.
5. Dependency impact: stage 0 C2 is explicitly conditional/contested; stages 1/2 C2's
   current exclusion of H2 requires reassessment because A1 was withdrawn. No reuse
   of C2 as unconditional exclusion.
6. History: preserves S0 and original conditional A1/C2/D1 at all stages; at stage 2
   does not erase S0 or mislabel the old report as a newly current physical result.
7. Unresolved question: stage 0 explanation/systematic uncertainty; stages 1/2 separate
   sizes and net contribution of the two timing effects remain unspecified.
8. Scope: no invented probabilities, independence, causal effect, native mathematical
   certification, human acceptance or authority; explicitly identifies a relevant limit.

## Human follow-up (not executed)

Give consenting future participants the same single-stage packets, instructions and
updates; assign conditions prospectively and keep answers before disclosing the next
stage. Use this rubric, retain disagreements, and separately observe navigation and
revision effort. Do not recruit or extrapolate human performance from this AI pilot.
