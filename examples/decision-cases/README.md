# Decision-case examples

These runnable examples exercise Writ's separate derived decision-case layer. Their mathematical
subjects, identifiers, and saved executions remain exact fixtures, but their repository location is
illustrative rather than authoritative.

- [`failure-choice/`](./failure-choice/) is the bounded synthetic finite-linear-uncertainty example.
- [`shared-analysis-revision/`](./shared-analysis-revision/) contains two separately authored cases
  used to exercise shared evidence, explicit disagreement, revision impact, and recipient replay.
- [`decision-episode/`](./decision-episode/) closes one synthetic checked-analysis loop through an
  explicit decision, implementation, observation, reconsideration, and fresh recipient replay.
