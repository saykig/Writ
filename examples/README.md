# Examples

The examples serve different purposes:

- `2025-ai-sme-literal.writ` normalizes “up to four strong actions” as one through four, exposing a weak-count gap and the independent counteraction overlap.
- `2025-ai-sme-inclusive-up-to.writ` normalizes the same phrase as zero through four, removing that gap but producing an overlap with the non-compliance branch.
- `2025-ai-sme-resolved.writ` demonstrates an explicit interpretation profile with counteraction precedence and complete weak-action coverage.
- `2025-middle-east.writ` demonstrates dimensional scoring.
- `2025-critical-minerals.writ` demonstrates dimensions, partner classes, and required artifact completeness.
- `2025-infrastructure.writ` demonstrates partner-attribution and exclusion of domestic-only action.
- `2025-ai-sme-literal.ir.json` is a schema-valid canonical IR example.
- `2025-ai-sme.sample-evidence.json` is illustrative evidence data, not a claim about the live state of Canadian policy.
- `2025-ai-sme.sample-receipt.json` is an illustrative output contract.

The `.writ` syntax is a design target until the Langium parser is implemented and its examples are promoted into the conformance suite.
