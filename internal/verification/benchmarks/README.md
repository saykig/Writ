# Benchmarks

Benchmarks contain evaluator methodologies, expected computed results, discrepancy records, and
historical reproduction notes. They test Writ behavior but do not own political source records.
Authoritative source-grounded material belongs under [`../../../corpora/`](../../../corpora/).

- [`evaluator/g7-2025-ai-sme-score-reproduction/`](./evaluator/g7-2025-ai-sme-score-reproduction/)
  reproduces a historical published G7 score from the independent G7 corpus.
- [`evaluator/fatf-mutual-evaluation-scaffold/`](./evaluator/fatf-mutual-evaluation-scaffold/) is a
  source-gated methodology scaffold using synthetic test ratings; it contains no country corpus.
