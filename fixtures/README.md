# Diagnostic fixtures

These are compact, implementation-independent cases for the analyzer and review workflow. A production conformance corpus should add:

- exact source spans and diagnostic ordering;
- type and unit errors;
- temporal boundary behavior;
- four-valued quantifier behavior;
- action identity equivalence and uncertainty;
- attribution and partner-coverage cases;
- required-artifact completeness;
- prose-to-metric consistency checks;
- canonical receipt hashing and tamper detection.
