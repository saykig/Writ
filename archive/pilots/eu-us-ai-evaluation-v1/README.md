# EU-US AI evaluation pilot v1 archive

This directory preserves the complete combined pilot as historical evidence. It is not an active
corpus and is not normative.

`original/` is the original pilot tree moved without content changes. Its reviewed input is:

`original/annotations/human-reviewed.yaml`

SHA-256:

`8de1e3b84a15875a39f3de2857f68dcd3040830ad72ffd9728c1ded0eda07cbb`

The original tree contains the reviewed YAML, local schemas, normalized outputs, methodology
files, interpretation profile, source registry, source passages, document hashes, unresolved
coverage, evidence snapshots, and saved headline judgments.

`deep-research-report.md` is preserved as historical research context for the combined EU-US
pilot. It is not normative and is not part of either active jurisdictional corpus.

`reference-code/` preserves the original normalizer, headline derivation, source fetcher, emitter,
and snapshot builder. `reference-tests/` preserves the exact original acceptance and mutation test.
These files explain and reproduce the historical comparison; they are archive material, not active
runtime code.

`MANIFEST.sha256` covers every archived file except itself. The active successor corpora are:

- `corpora/jurisdictions/eu/ai-governance/`
- `corpora/jurisdictions/us/ai-governance/`

Their migration maps retain every reviewed `EU-##` and `US-##` identifier as a legacy reference.
