## What Writ was trying to do

Writ tried to separate reusable provenance mechanics from NIST-specific repository policy. The aim
was a portable, deterministic boundary for exact source identity, evidence-reference consistency,
canonical bytes, and fail-closed diagnostics that another caller could independently exercise.

## What existed at this checkpoint

Writ Canonical JSON v1 defined the existing JSON identity profile explicitly. Exact contract
dispatch and generic native provenance applied across legal-policy and institutional fixtures. The
portable provenance package exposed canonicalization, hashing, source indexing, and evidence
reference verification without importing Writ repository layouts, schemas, review workflows, or
NIST policy.

## Major decisions

No new ADR was added during this period. The work implemented narrower consequences of Accepted ADR
0004 (content-addressed provenance), ADR 0013 (schema/protocol authority), ADR 0016 (distinct
evidence meanings), ADR 0020 (deterministic verification), and ADR 0023 (NIST as a proving ground
rather than a generic architecture).

## What worked

The same portable mechanics agreed with Writ's native verifier across a differential suite.
Canonicalization rejected unsupported values and unsafe integer ambiguity while retaining protected
hash identities. Exact contract routing failed closed instead of using prototype-inherited or
unknown dispatch keys. Generic provenance checks no longer depended on NIST-specific code.

## What did not survive

The still-present database/storage infrastructure was later retired. NIST “closure” did not mean
the corpus was finished forever or that NIST defined the whole roadmap. The kernel was never a
complete grounding, review, or decision system; later work added those as separate layers rather
than expanding the kernel's claim.

## What survived

Writ Canonical JSON v1, exact byte identity, deterministic portable hashing, explicit source/version
resolution, caller-owned policy boundaries, and fail-closed provenance diagnostics remain the
mechanical waist of Writ.

## Known limitations at the checkpoint

A fabricated quote with a correct self-hash, declared source/version/document hash, and arbitrary
locator intentionally passed the portable reference checker. The caller still had to prove
document-to-locator-to-quote grounding. The kernel did not authenticate reviewers, establish
evidentiary sufficiency, or supply decision semantics.

## What changed next

Writ tested one bounded XML paragraph-grounding profile, clarified its product/research boundary,
bound judgments to exact review-artifact bytes, and used a temporary cross-layer experiment to find
consistency defects.

## Current retrospective

This checkpoint established a durable narrow waist: portable mechanical provenance with explicit
limits. Its value lies as much in the caller-owned grounding gap as in the checks it performs.
